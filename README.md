# Hotel Room Booking System

## Project Description

The Hotel Room Booking System is a web-based application developed to manage hotel room bookings and related hotel operations efficiently.

The system provides a user-friendly interface for users to view hotel information, manage room booking details, and handle data through a backend server and database.

This project was developed as an academic project to gain practical experience in web development, backend programming, and database management.

## Technologies / Tools Used

- HTML
- CSS
- JavaScript
- Node.js
- SQLite
- Visual Studio Code
- npm

## Features

- User Login
- Hotel Room Booking
- Room and Hotel Information Management
- Database Management
- User-friendly Web Interface
- Backend Server using Node.js
- Persistent Data Storage using SQLite
